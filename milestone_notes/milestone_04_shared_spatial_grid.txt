RFE MILESTONE NOTE

Milestone 04 — Shared 5 × 5 Spatial Grid + Routing Inspection Layer

Status:
COMPLETE — 2026-08-11

OBJECTIVE
Establish one canonical 25-point Cartesian spatial field shared by Sound Desk and Visualiser, prove independent channel assignment/reassignment/unassignment, and expose live routing state through a lightweight Visualiser inspection layer.

CANONICAL COORDINATE MODEL
- `app/spatial-routing.ts` is the only coordinate definition.
- X and Y values are both -2, -1, 0, 1, 2, producing exactly 25 unique points.
- Screen orientation follows Cartesian convention: X increases left to right; Y increases bottom to top. The top rendered row is Y=2, the bottom row is Y=-2, and the centre cell is (0,0).
- Coordinates are immutable shared values consumed through one reusable SpatialGrid renderer.

ROUTING STATE
- The application shell owns one spatialRouting reducer state, independently of the existing Threads AppState.
- Each channel owns an optional coordinate assignment. Coordinates do not own a single channel slot.
- `getChannelsAtCoordinate` derives zero, one, or multiple channel records from authoritative channel state. This deliberately permits future stacked routing without implementing stacked interaction or mixing in Milestone 04.
- Assigning a channel replaces only that channel's assignment. Unassigning retains channel identity with a null assignment.

- CH 01 -> (0,0)
- CH 02 -> (-2,-1)
- CH 03 -> (1,2)
- CH 04 -> (-1,1)
- CH 05 -> (2,0)
- Five channels are the current minimum active UI fixture, not an architectural maximum.
- CH 01 through CH 05 automatically use Muted Coral, Warm Stone, Moss Green, Utility Blue and Air Blue respectively from the canonical muted palette.

SOUND DESK
- Displays all 25 points, coordinate labels, an identifiable origin, occupied nodes, and orientation guidance.
- Uses the approved lightweight plot treatment: 70%-opacity mid-grey dashed axes and enlarged circular intersection markers showing `x,y` while empty and zero-padded channel numbers such as `01` when occupied.
- A clearly labelled development-fixture panel supplies temporary coordinate selectors for assign/reassign/unassign testing.
- The grid is square and uses the same canonical point order at desktop, tablet and compact widths.

VISUALISER
- Remains a non-simulation surface.
- A lightweight toggle reveals or hides a translucent routing inspection layer.
- The overlay renders the same SpatialGrid component and the same spatialRouting state as Sound Desk.
- Occupied nodes carry channel identifiers; empty points remain visually quiet; orientation and origin remain visible.
