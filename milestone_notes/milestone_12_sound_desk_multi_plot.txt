USER-FACING WORKFLOW

- Threads no longer offers Clone as a source action. Duplicate remains available and retains independent source/programming semantics.
- Sound Desk owns Multi-Plot. An already plotted, routable Channel Out can add spatial manifestations with one MULTI-PLOT action.
- Each plot has its own X/Y position, Live Trim, mute state, selection, and quick removal. Pointer drag snaps decisively to the nearest canonical grid-point centre. Removing one Multi-Plot does not remove its source, Thread, sibling plots, or unrelated routing.
- Source deletion presents an explicit warning when associated Multi-Plots exist. Sidebar, toolbar, batch, and keyboard deletion paths guard the source-owning object.
- Plotter Modes opens a compact overlay containing active MANUAL PLOTTER plus disabled AUTO PLOT and ORCHESTRA placeholders. No future-mode behavior is hidden behind them.

ARCHITECTURE AND REUSE

- Spatial state distinguishes the original Channel Out plot from additional Multi-Plot endpoint identities. Extra endpoint IDs remain Sound Desk-owned and do not create Threads cards, Channel Out terminals, or wires.
- The proven Clone-family audio mechanics are reused below the UI boundary: each Multi-Plot endpoint maps to the original sourceId and receives an independent programmed-gain branch, Live Trim gain, analyser, stereo panner, routing state, and scoped disposal lifecycle.
- One source family retains one oscillator and one source envelope. Frequency and programmed level remain source-owned and immediately apply to every manifestation.
- Equal-power family scaling remains `1 / sqrt(N)` and is recalculated when a plot is added or removed. All endpoints still converge through the accepted session/master/native-fence output-safety path.
- Duplicate still creates a new sourceId, oscillator, programming state, and independent family.

LIVE DRAG AND POINTER LIFECYCLE

- Plot nodes use pointer capture and handle pointer down, move, up, leave, cancel, and lost capture without document-level listeners.
- Pointer coordinates resolve against the measured centres of the 25 actual coordinate cells and snap to the nearest canonical point. A visible target ring confirms grid engagement. A cancelled or lost drag commits its last valid position; rapid subsequent drags remain usable.
- The plot overlay is inset by the same responsive padding as the CSS grid. Plot percentages therefore use the same inner coordinate box as the coordinate circles, eliminating the increasing position error away from the origin.
- Pointer movement is coalesced to requestAnimationFrame. Each frame modulates only the existing endpoint panner through the established 20 ms AudioParam ramp.
- The hot path suppresses runtime subscriber notification, so React does not rerender the whole Sound Desk for each pointer sample. The final position is committed once to the spatial reducer.
- Runtime diagnostics prove repeated movement changes smoothing-ramp counts while oscillator, source, channel, analyser, and panner creation counts remain fixed.
