AUTHORITATIVE CHANNEL STATE

AppState.threadChannels is the authoritative channel collection. Each channel is a complete,
stable record containing id, label, short label, and accent. Threads, channel output terminals,
Sound Desk, the Channel Plotter, and Visualiser all derive their visible channel population from
that collection.

The spatial reducer accepts sync-channels. It preserves assignments for identities that survive,
adds new identities unassigned, and drops removed identities and their assignments. Terminal
connections remain keyed by stable channel ID.

IDENTITY AND LIFECYCLE

Channels use monotonic IDs (channel-01, channel-02, ...). nextChannelSequence is never reduced
when a channel is removed, so deleting CH 02 does not renumber CH 03 or cause a later channel to
reuse CH 02's persistent identity. Accent colors cycle independently of identity and do not impose
a channel-count ceiling.

The default state contains one active, complete CH 01. Add Channel appends an incomplete channel
and its output terminal. A module output may then complete that channel. Removal deletes only the
target channel and its terminal connection; spatial synchronization removes only its downstream
route. Modules, Threads, peer channels, and peer assignments are preserved.

THREADS INTERFACE

The former prototype navigation sidebar is replaced by collapsible Inputs & Channels. It contains
the functional Add Channel action, active channel selection/removal, and visually subordinate text
reserving future source categories without exposing fake controls. Collapsing it leaves channel,
selection, Thread, and node state untouched while increasing canvas width.

The top toolbar remains the home of select, pan, grid, session, zoom, and layout controls. A
keyboard-accessible More tools control reveals module creation, workspace width, selection,
duplication/deletion, preset, and save operations. This establishes a future manipulation-tool home
without implementing speculative ordering or composition features.

MONITOR AND DIAGNOSTICS

The user-facing Diagnostics panel is now Monitor. It follows module, multi-module, Thread, and
channel focus; shows current channel context and active channel count; exposes the selected object
type and immediately relevant display values; and provides a static, accessible NO SIGNAL area for
Milestone 07. It performs no audio work and has no decorative animation or render loop.

State Updates is no longer rendered. The underlying AppState.updateCount instrumentation and
withUpdate behavior are preserved unchanged for later engineering diagnostics review. No backend
diagnostic infrastructure was deleted. No Visualiser diagnostics UI was added; the primary
Visualiser and routing inspection remain clean.

PERFORMANCE / LOCAL-FIRST

No remote API, hosted database, CDN, authentication, server processing, audio processing, polling,
or cloud runtime dependency was introduced. The existing session display interval now runs only
while a session is active and updates once per second. The signal area is static. Channel state is
not duplicated into independent workspace fixtures.
